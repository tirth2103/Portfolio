==========================================
   HOW TO ENABLE EMAIL NOTIFICATIONS
==========================================

STEP 1: Get Gmail App Password
-------------------------------
1. Go to: https://myaccount.google.com/apppasswords
2. Sign in with: tirthpatel1617@gmail.com
3. If asked, enable 2-Step Verification first
4. Select "Mail" as the app
5. Select "Other" and type "Portfolio"
6. Click "Generate"
7. COPY the 16-character password (like: abcd efgh ijkl mnop)

STEP 2: Update the Configuration File
--------------------------------------
1. Open this file: /app/backend/.env
2. Find this line:
   SMTP_PASS=REPLACE_WITH_YOUR_16_CHARACTER_APP_PASSWORD
   
3. Replace "REPLACE_WITH_YOUR_16_CHARACTER_APP_PASSWORD" with your actual password
   Example:
   SMTP_PASS=abcdefghijklmnop
   (remove spaces if any)

STEP 3: Restart the Backend
----------------------------
Run this command in terminal:
   sudo supervisorctl restart backend

STEP 4: Test It!
----------------
1. Go to your portfolio website
2. Fill out the contact form
3. Submit it
4. Check your email: tirthpatel1617@gmail.com
